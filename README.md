# Legendary Soaks crafting board

Who in the Legendary Soaks guild can craft what in **WoW: Forever**: search a recipe or reagent, see who already
knows it and who is closest to learning it, browse recipes by profession, and see everyone's characters.

The data (`data.json`) comes from the guild's own in-game probe addon, exported after each probe file the guild
drops into its Discord. It holds game data only: character names, levels, races, classes, professions, recipes and
the library book list.

Unofficial fan tool, not affiliated with Blizzard Entertainment or WoW: Forever. Page code: MIT (see LICENSE).

## Maintainers

The page is static (`index.html` + `data.json`, GitHub Pages from `main` /). `data.json` is generated by the
guild's private tooling after each probe-file merge and pushed here automatically; nothing else in this repo
changes on its own.

Only commit `data.json` produced by that exporter: it allowlists fields and filters every value (a test proves no
Discord tags or IDs, real names, notes or paths get through).
